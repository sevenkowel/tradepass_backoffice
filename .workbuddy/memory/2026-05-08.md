## Dev Server 修复（端口 3003）

### 内存爆满原因
- `--turbopack` 启动命令 + Next.js 16 默认已启用 Turbopack，双重配置冲突致内存泄漏
- `webpack.watchOptions.poll: 1000` 每秒轮询 38k+ 文件 → CPU + 内存爆炸
- `.next` 缓存积累 1GB

### 修复操作
- 移除 `next.config.ts` 中已废弃的 `experimental.turbo` 配置
- 移除 `watchOptions.poll: 1000`，改用系统原生 fs 事件
- 移除 `config.devtool` 自定义（Next.js 16 不支持手动设置 devtool）
- 清理 1GB `.next` 缓存
- 启动命令改为 `next dev --webpack -p 3003`（避免 Turbopack 冲突）
