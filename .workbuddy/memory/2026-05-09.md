## CRM 菜单性能优化（Sidebar.tsx）
- **问题**: 菜单点击卡顿，每次导航触发 Sidebar 全量重渲染 + 60+ 项权限过滤 + 13 个 MenuItem 全部 useState
- **方案 B 实施** (1 文件改动):
  1. `SubMenuItem` / `SubMenuGroup` / `MenuItem` 三个子组件 → `React.memo` 包裹，阻止不必要的 VDOM diff
  2. `isActive` / `toggleGroup` / `toggleAppItem` → `useCallback` 包裹，稳定函数引用使 memo 生效
  3. `filteredMenuGroups` 优化 → super_admin 直接返回静态 `menuGroups`，跳过 60+ 项权限遍历
  4. `useEffect` 自动展开 → 移除 `filteredMenuGroups` 依赖，仅依赖 `[pathname]`
- **效果**: 菜单点击时减少 3 项重量操作（权限过滤/全量遍历/子组件重渲染）
- **无新增 TypeScript 错误**
